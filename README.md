# Choso Island

A Dynamic Island–style utility for macOS — music, lyrics, calendar, battery, and more, right in the notch.

**[Download Choso Island](https://github.com/Mikey01-ui/choso-island/raw/main/Choso-Island.dmg)** · Apple Silicon (arm64)

## Install

1. Download [`Choso-Island.dmg`](https://github.com/Mikey01-ui/choso-island/raw/main/Choso-Island.dmg)
2. Open the disk image
3. Double-click **Install Choso Island** — it copies the app to Applications, clears the download lock, and opens Privacy & Security if macOS asks you to allow it
4. Or drag **Choso Island.app** onto the **Applications** folder yourself

Requires macOS on Apple Silicon.
