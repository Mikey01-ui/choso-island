# Choso Island

A Dynamic Island–style utility for macOS — music, lyrics, calendar, battery, and more, right in the notch.

**[Download Choso Island](https://github.com/Mikey01-ui/choso-island/raw/main/Choso-Island.zip)** · Apple Silicon only

## Install

1. Download [`Choso-Island.zip`](https://github.com/Mikey01-ui/choso-island/raw/main/Choso-Island.zip)
2. Unzip it
3. Move **Choso Island.app** to your **Applications** folder
4. Open it (see Gatekeeper note below)

### If macOS says “Choso Island” Not Opened

Apple shows this because the app is not from the App Store / not notarized. That’s expected.

1. Click **Done** on the warning
2. Open **System Settings → Privacy & Security**
3. Scroll down to the **Security** section
4. Click **Open Anyway** next to Choso Island
5. Confirm **Open**

After that, Choso Island launches normally. Grant **Accessibility** if macOS asks (needed for volume / brightness).
